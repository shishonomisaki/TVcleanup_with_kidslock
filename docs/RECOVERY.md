# 救援：電視解不開時怎麼辦

家長鎖讓電視**預設是鎖著的**，平常只能用手機頁解鎖。手機頁連不到電視時，電視就會一直鎖著。
這份文件說明怎麼事先準備，以及每一種狀況要怎麼救。

**安裝完第一件事：產生救援碼（下面「1. 事先準備」）。** 沒有救援碼，下面大部分狀況都只剩恢復原廠設定。

---

## 1. 事先準備（安裝後 5 分鐘內做完）

1. **產生救援碼**：手機頁 → 時間分頁最下面「更多」→「救援碼」→ 輸入 PIN →「產生救援碼」。
   - 會顯示一組 **10 位數**，只顯示這一次。
   - 馬上存進**密碼管理器**，或寫在紙上收在小孩拿不到的地方。不要只記在腦子裡。
   - 再按一次「換一組新的」，舊的就作廢。
   - 還沒產生救援碼時，手機頁「更多」旁邊會一直顯示 ⚠。
2. **關掉電視的 Tailscale 金鑰到期**：login.tailscale.com → Machines → 電視那台 → ⋯ → **Disable key expiry**。
   不關的話，電視的 Tailscale 登入預設約 180 天後失效，手機就連不到電視。
3. **確認版本至少是 v1.1.1**：手機頁「更多 → 更新」看目前版本。舊版沒有 Tailscale 自動重連。
4. **（有樹莓派轉送程式的人）** 裝好 v1.2.0 以後的 `pi-relay/relay.py`：電視自己的 Tailscale 斷線時，
   手機頁會經由樹莓派走家裡 Wi-Fi 連到電視，平常用起來沒有差別。

---

## 2. 用救援碼解鎖（只要電視和實體遙控器）

不需要手機、網路或 PIN。

1. 電視停在鎖定畫面（黑底「現在不是看電視的時間唷！」）。
2. 用電視的**實體遙控器**，**按住 OK 鍵 5 秒**，畫面下方會出現「救援碼」輸入框。
3. 輸入 10 位數：
   - **上／下**：換目前這一格的數字
   - **左／右**：移到前一格／後一格
   - **數字鍵**（遙控器有的話）：直接輸入，自動跳到下一格
   - **返回**：關掉輸入框
4. 按 **OK** 送出。
5. 正確的話會出現選單，用上／下選、OK 確定：

   | 選項 | 用在什麼時候 |
   |---|---|
   | 解鎖 60 分鐘 | 只是手機暫時連不上，先讓電視能看 |
   | 解鎖並開放電視設定 15 分鐘 | 要修 Wi-Fi、Tailscale，打開 ADB，或在設定裡做其他事 |
   | 解鎖並清掉 PIN | 忘記 PIN。之後打開手機頁會要你設定新的 PIN |
   | 移除家長鎖 | 整個不要了。電視會跳出 Android 的移除確認，按確定；之後電視就完全不鎖 |

6. **救援碼用過就作廢**：問題解決後，到手機頁「更多 → 救援碼」產生一組新的。

**輸入錯誤**：可以一直重試，次數沒有上限。錯第 3 次要等 1 分鐘，之後每錯一次要等 10 分鐘。
電視重開機也不會重算。10 位數一共一百億種組合，每 10 分鐘試一次的話，平均要好幾萬年才猜得中。

## 3. 各種狀況怎麼救

| 狀況 | 看到什麼 | 怎麼救 |
|---|---|---|
| 電視的 Tailscale 被系統關掉 | 手機頁打不開，約 2 分鐘後自己恢復 | 等 2 分鐘。還是不行 → 救援碼「開放電視設定」，打開 Tailscale App 連線 |
| 電視的 Tailscale 登出／金鑰到期 | 手機頁一直打不開 | 有樹莓派轉送：手機頁照常能用，用它解鎖後到電視上重新登入 Tailscale。沒有 → 救援碼「開放電視設定」，打開 Tailscale 重新登入 |
| 換路由器、Wi-Fi 密碼改了 | 手機頁打不開，電視也上不了網 | 救援碼「開放電視設定」→ 設定 → 網路，重新連 Wi-Fi |
| 忘記 PIN | 手機頁一直說 PIN 不對 | 救援碼「清掉 PIN」，再到手機頁設定新的 |
| 手機的 Tailscale 出問題 | 只有這支手機打不開 | 手機上重新登入 Tailscale；或用另一位家長的手機 |
| 家長鎖本身壞掉、一直打不開 | 手機頁打不開，電視一直鎖著 | 先把電視拔電重開。還是不行 → 救援碼「移除家長鎖」 |
| 救援碼也弄丟了 | — | 電腦有 ADB 的話：`am broadcast -n io.github.shishonomisaki.parentlock/.AdminReceiver -a UNLOCK --ei minutes 60`。都沒有 → 只能恢復原廠設定 |

---

## 4. 電腦上的 ADB 救援（進階）

電視的網路 ADB（port 5555）是用 `adb tcpip` 打開的，**電視重開機後就會關掉**；電視鎖住時又進不了設定把它打開。
所以 ADB 不能當作唯一的救援方式，救援碼才是。

ADB 還開著的時候可以用（在 `upstream/cleanyourtv` 裡，`TV_HOST=<電視 IP>`）：

```sh
tools/venv/Scripts/python.exe -I tools/tv.py 'am broadcast -n io.github.shishonomisaki.parentlock/.AdminReceiver -a UNLOCK --ei minutes 60'
tools/venv/Scripts/python.exe -I tools/tv.py 'am broadcast -n io.github.shishonomisaki.parentlock/.AdminReceiver -a SET_PIN --es pin <6 位數>'
```

**不要用 `am force-stop` 停掉家長鎖**：Android 會把它的無障礙服務標成「當機」並停用，電視就沒有鎖了，
而且不會自己恢復。要讓它重新啟動，就重新安裝一次 APK（`install.sh`）。

---

## 5. 恢復原廠設定（最後手段）

會清掉電視上所有 App、帳號和設定，家長鎖也會一起不見。
電視解鎖時：設定 → 裝置偏好設定 → 重設。電視鎖住時進不了設定，所以要先用救援碼解鎖。

---

## 給協助救援的 AI 助理

這一節寫給幫使用者處理的 AI（ChatGPT、Codex 等）。

- **先說明、再確認、才動手**：任何會改變電視的操作（ADB 指令、清掉 PIN、移除家長鎖、恢復原廠設定），
  都要先跟使用者說清楚會發生什麼、會失去什麼，取得使用者明確的同意之後才執行。沒有明確同意就停下來。
- **救援順序**：先等 2 分鐘（Tailscale 自動重連）→ 救援碼 → ADB（還開著的話）→ 最後才是恢復原廠設定。
  不要一開始就建議恢復原廠設定。
- **救援碼由使用者自己在電視上輸入**：不要要求使用者把救援碼或 PIN 貼給你。
- **不要用 `am force-stop` 停掉家長鎖**，理由見「4. 電腦上的 ADB 救援」。
- 救援結束後，提醒使用者到手機頁產生新的救援碼（用過的那組已經作廢）。
